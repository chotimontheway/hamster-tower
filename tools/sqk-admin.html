SQK contract for Hamster Tower

This page runs on your own computer. It only prepares transactions, and your wallet asks you to sign each one. It never sees a key.

1. Wallet

Not connected.

2. The game's signer

The game server signs how much SQK each wallet earned. The contract must trust its address. Read it from the game: the one on this computer for a trial, or https://www.hamstertower.site when going live.

3. Deploy the contract

Your wallet asks twice: once to make the contract, once to set the price.

4. Attach it to the game on this computer

The game you run with npm start then sells the SQK Chest through this contract and pays rewards from it. The live site is not touched; it only changes when SQK_SHOP is set on Vercel.
